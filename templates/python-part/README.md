```sh

```

`OPENROUTER_API_KEY` plus the exact model ID recorded for this lesson.

## Run

```sh
uv run --locked python -m tutorials.SERIES.part_NN.main
```

Replace `SERIES` and `NN` with the real package names before publishing.
Do not require an earlier part to run first.
